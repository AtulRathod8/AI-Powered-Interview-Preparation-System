# 🚀 Quick Start Guide

## Get Started in 3 Steps

### 1️⃣ Install Dependencies
```bash
npm install
```

### 2️⃣ Build the Project
```bash
npm run build
```

### 3️⃣ Start Using (Development)
```bash
npm run dev
```
Then open **http://localhost:3000** in your browser.

---

## 📋 What You'll See

1. **Camera Permission Request** - Click "Allow"
2. **Video Feed** - Your webcam will activate
3. **Hand Detection** - Green lines and red dots appear on your hand
4. **Gesture Recognition** - Make a sign and see it detected
5. **Text Output** - Recognized gestures appear as text

---

## ✋ Try These Gestures

### Easy Ones to Start
- **Thumbs Up** 👍 - Thumb extended, other fingers closed
- **Peace Sign** ✌️ - Index and middle fingers in V
- **Number 5** - All five fingers spread open
- **Letter L** - Index finger up, thumb out at 90°

### Tips for Success
- ✅ Hold gesture steady for 1-2 seconds
- ✅ Keep hand centered in camera view
- ✅ Use good lighting
- ✅ Position hand 1-2 feet from camera

## ❓ Troubleshooting

### Camera Not Working?
- Check browser permissions (Settings → Privacy → Camera)
- Refresh the page
- Try a different browser

### Gestures Not Detected?
- Improve lighting
- Move closer to camera
- Make clearer hand shapes
- Hold gesture longer

### Build Errors?
```bash
# Reinstall dependencies
rm -rf node_modules package-lock.json
npm install
npm run build
```
